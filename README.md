# Newton's method

We define the Newton endomorphism $N_f:\mathbb{C}\to\mathbb{C}$ by
$$
N_f(z)=z-\frac{f(z)}{f'(z)}.
$$
This yields the Newton iteration $z_{n+1}=N_f(z_n)$ used to approximate roots of $f$.
